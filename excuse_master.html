핑계의 정석 (Excuse Master) 시스템 구조 & 발전 방향

본 서비스는 단순 랜덤 텍스트 생성이 아닌, 사용자-상대방 연관 데이터베이스와 Gemini API Prompt Engineering을 결합하여 관계의 손상을 최소화하는 회피 기술을 제공합니다.

1

현 알고리즘 구축 포인트

  • 상대별 히스토리 메모리: Firestore DB 연동으로 특정 인물(예: 부장님)에게 중복 핑계가 지급되는 것을 방지.
  • 시간적 타당성 계산: 약속 남은 시간(1시간 전 vs 하루 전)에 따라 허용 가능한 핑계 카테고리를 프롬프트 단에서 자동 제한.
  • Structured JSON Output: Gemini API의 `responseSchema`를 활용하여 3종 옵션, 신뢰도 점수, 대응 팁을 정형화 데이터로 반환.
2

향후 기능 보완 및 확장 로드맵

  • AI 음성 통화 / TTS 핑계 연동: Gemini Live API 및 TTS API를 결합하여 실제 진단서 알림음이나 쿨럭거리는 목소리 핑계 음성 생성.
  • AI 이미지 증거 연동: Gemini Nano Banana(Flash Image) 모듈로 '지하철 고장 안내판', '병원 접수표' 등의 가상 이미지 증거 생성 기능 연동.
  • 캘린더 연동 자동 일정 재조정: 핑계 발송 후 상대방의 긍정적 답장에 맞춰 Google Calendar 자동 여유 일정 제안.
